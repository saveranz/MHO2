## 🚀 How to Use

### View a Report:
1. Go to **Reports** tab
2. Click **"View Report"** on any card
3. Browse detailed data
4. Download as PDF or CSV

### Download an Export:
1. Go to **Reports** tab
2. Find **"Quick Exports"** section
3. Click any export button
4. File downloads automatically

## 📁 File Naming Convention

All downloads follow this format:
```
filename-YYYY-MM-DD.extension
```

Examples:
- `weekly-consultation-2026-05-13.txt`
- `consultation-log-export-2026-05-13.csv`
- `staff-attendance-report-2026-05-13.csv`
