# Reports & Exports - User Guide

## 📍 Where to Find It

1. Login to Admin Dashboard
2. Click **"Reports"** in the left sidebar
3. You'll see two main sections:
   - **Available Reports** (left side)
   - **Quick Exports** (right side)

---

## 📊 Section 1: Available Reports

### What You'll See:

Three report cards, each showing:
- **Title** (e.g., "Weekly consultation summary")
- **Period** (e.g., "Week of May 6-12, 2026")
- **Type Badge** (cyan pill showing category)
- **Summary** (brief description)
- **Two Buttons:**
  - 🔵 **"View Report"** (blue gradient button)
  - 📥 **Download icon** (outline button)

### How to Use:

#### Option 1: View Report Details
1. Click **"View Report"** button
2. A large modal window opens showing:
   - **Header:** Report title and period
   - **Content:** Detailed statistics with:
     - Color-coded summary cards
     - Service breakdowns
     - Progress bars
     - Daily/weekly statistics
     - Visual grids
   - **Footer:** 
     - Generation date
     - "Export CSV" button
     - "Download PDF" button

3. **Inside the Modal:**
   - Scroll to see all data
   - Click **"Export CSV"** for spreadsheet format
   - Click **"Download PDF"** for document format
   - Click **X** (top-right) to close

#### Option 2: Quick Download
1. Click the **📥 download icon** on the report card
2. File downloads immediately as TXT format

---

## 📥 Section 2: Quick Exports

### What You'll See:

Four export buttons, each showing:
- **Colored icon** (indicates file type)
- **Export name** (e.g., "Monthly office summary")
- **Format label** (PDF Format or CSV Format)
- **Download icon** (right side)

### Export Types:

1. **📄 Monthly Office Summary** (Red icon - PDF)
   - Complete office statistics
   - Staff performance metrics
   - Resource utilization

2. **📋 Consultation Log Export** (Green icon - CSV)
   - Patient records
   - Doctor assignments
   - Service details
   - Perfect for Excel

3. **💉 Immunization Progress Summary** (Blue icon - PDF)
   - Vaccination coverage
   - Age group breakdown
   - Recommendations

4. **👥 Staff Attendance Report** (Amber icon - CSV)
   - Attendance rates
   - Leave tracking
   - Performance data

### How to Use:

1. Click any export button
2. File downloads automatically to your Downloads folder
3. File name includes date: `filename-2026-05-13.ext`

## 💡 Pro Tips

1. **Preview Before Download**
   - Always click "View Report" first
   - Review the data
   - Then choose your download format

2. **Choose the Right Format**
   - **PDF** for: Printing, sharing, presentations
   - **CSV** for: Data analysis, Excel, databases

3. **File Organization**
   - Files include dates in filename
   - Easy to organize chronologically
   - No duplicate name conflicts

4. **Regular Exports**
   - Download weekly for records
   - Keep monthly archives
   - Build historical data

5. **Data Analysis**
   - Open CSV in Excel
   - Create pivot tables
   - Generate custom charts
   - Compare time periods

## 🆘 Troubleshooting

### Report won't open?
- Refresh the page
- Check if you're logged in
- Try a different browser

### Download not working?
- Check browser download settings
- Allow pop-ups for this site
- Check Downloads folder

### CSV looks weird?
- Open in Excel/Sheets (not Notepad)
- Check delimiter is set to comma
- Ensure UTF-8 encoding

### Can't find downloaded file?
- Check your Downloads folder
- Look for filename with today's date
- Search for `.txt` or `.csv` files
